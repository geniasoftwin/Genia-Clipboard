# Участие в разработке GeniaClipboard

[English](CONTRIBUTING.md) · **Русский**

Спасибо за интерес к проекту.

## Требования

- Windows 10/11 x64;
- .NET 8 SDK или Visual Studio с workload для классических .NET-приложений;
- Git.

## Локальная сборка

```powershell
dotnet restore GeniaClipboard.csproj
dotnet build GeniaClipboard.csproj -c Release
dotnet publish GeniaClipboard.csproj -c Release
```

Либо используйте `build-portable.cmd`.

## Перед pull request

Проверьте обычное копирование текста, дубли, защиту от самокопирования, multi-select, пакетное копирование/вставку, поиск, закрепление, удаление, TXT-экспорт, автожурнал, `Ctrl+Shift+V` и работу из трея.

Не добавляйте в issue, логи, скриншоты или тестовые файлы реальные пароли, токены, персональные данные и содержимое чужого буфера обмена.

## Стиль изменений

- сохраняйте существующий стиль C# и nullable-аннотации;
- не добавляйте зависимости без реальной необходимости;
- сопровождайте изменения поведения буфера явным тестовым сценарием;
- учитывайте ограничения WinAPI, включая возможный отказ `SetForegroundWindow`;
- изменения безопасности описывайте отдельно в PR.

## Сообщения об ошибках

Укажите версию GeniaClipboard, версию Windows, шаги воспроизведения, ожидаемое и фактическое поведение. Никогда не публикуйте секретные данные из буфера обмена.
