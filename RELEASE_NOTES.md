# GeniaClipboard 0.5.7 — RU / English UI (Beta Candidate)

[Русский ниже](#русский)

## English

- **Automatic language choice:** Russian UI when Windows UI language is Russian (ru); **English for all other system languages**.
- **Manual language override:** Settings → System → Language: Automatic (Windows), Русский, or English. Changes are saved locally and take effect after restarting the application.
- **About dialog:** App version, MIT License, direct links to the source repository and bug reports, and a concise privacy/security limitation.
- **Interface localization:** main window, clipboard list/search, preview, buttons, Settings pages, Portable Vault password dialog, editor, tray menu, confirmations and key notification messages.
- **No conversion of stored data:** encrypted history, stored clips, password and vault format are preserved unchanged.

This is a beta candidate. Real Windows tests at common scaling levels and both Russian and English UI languages are needed before final release.

## Русский

- **Автоматический выбор языка:** если язык интерфейса Windows русский (`ru`), программа запускается на русском; **любой другой язык системы выбирает английский интерфейс**.
- **Ручной выбор:** Настройки → Система → Язык: Автоматически (Windows), Русский, English. Выбор сохраняется в настройках и применяется после перезапуска приложения.
- **О программе:** версия, MIT License, ссылки на исходный код и сообщения об ошибках, пояснение ограничений безопасности.
- **Локализация интерфейса:** главное окно, история, поиск, предпросмотр, кнопки, настройки, разблокировка Portable Vault, редактор, трей и основные уведомления/подтверждения.
- **История и Vault не изменяются:** не переводим содержимое записей, не меняем формат шифрования и мастер-пароль.

Это кандидат в бета-релиз. Перед выпуском требуется проверить интерфейс на реальной Windows при русском/английском языках и разном масштабе экрана.
