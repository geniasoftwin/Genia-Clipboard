# GeniaClipboard — чек-лист проверки перед релизом

**Назначение:** проверка исправлений после 0.5.2, прежде всего кнопки **«Вставить»** и иконки окна **«Изменить запись»**. Составлен по сообщениям пользователя и скриншотам. Сам по себе этот документ **не подтверждает**, что пункты уже исправлены.

**Тестовые данные:** используйте только вымышленные строки, например `GC-TEST-ONE`, `GC-TEST-TWO`, `https://example.com/page?a=1`. Не используйте пароли, реальные токены и личную информацию.

## Подготовка

- [ ] Сохранить резервную копию текущего каталога `Data` **до установки новой сборки**.
- [ ] Записать версию GeniaClipboard, Windows 10/11, x64 и масштаб экрана (100%, 125% или 150%).
- [ ] Закрыть все запущенные экземпляры GeniaClipboard; убедиться, что не остался процесс в трее.
- [ ] Создать тестовую запись `GC-TEST-ONE` копированием из Блокнота.
- [ ] Убедиться, что история открывается по настроенной комбинации (по умолчанию `Ctrl+Shift+V`).

## P0 — критично: кнопка «Вставить» не работает

**P-01. Вставка в Блокнот из глобального хоткея**

1. В Блокноте набрать `BEFORE |`, поставить курсор после вертикальной черты.
2. Из Блокнота открыть GeniaClipboard сочетанием `Ctrl+Shift+V`.
3. Выбрать `GC-TEST-ONE` и **нажать кнопку «Вставить»**, не `Ctrl+C`.

- [ ] Блокнот становится активным окном.
- [ ] `GC-TEST-ONE` появляется в позиции курсора **ровно один раз**.
- [ ] В истории не возникает новой записи от самой GeniaClipboard.

**P-02. Вставка клавишей Enter**

- [ ] Повторить P-01, но вместо кнопки нажать `Enter`. Результат совпадает.

**P-03. Двойной клик по записи**

- [ ] Повторить P-01 двойным кликом по нужной строке истории. Вставка выполняется один раз.

**P-04. Несколько выбранных записей**

- [ ] Выделить две тестовые записи с `Ctrl`/`Shift` и нажать «Вставить».
- [ ] В Блокноте появляются обе записи в порядке отображения, разделённые переводом строки, без потерь и дублей.

**P-05. Открытие окна из трея/кнопкой мыши**

- [ ] Открыть GeniaClipboard из трея, выбрать запись и нажать «Вставить».
- [ ] Если целевое окно известно — данные вставляются в него; если целевое окно неизвестно, **ничего не вставляется в случайное приложение**, а интерфейс понятно сообщает об отмене. Текст можно вставить вручную через `Ctrl+V`.

**P-06. Безопасность фокуса**

- [ ] Пока открыт GeniaClipboard, переключиться в другое приложение и вернуться; «Вставить» **не** вставляет текст в неожиданное окно.
- [ ] Если Windows не разрешает активировать целевое окно, приложение не отправляет `Ctrl+V` вслепую и не теряет содержимое буфера.
- [ ] При повторных быстрых нажатиях не происходит двойной вставки от одного действия.

**P-07. Кнопка «Копировать»**

- [ ] «Копировать» только помещает выбранную запись в системный буфер и **не** отправляет `Ctrl+V`.
- [ ] После «Копировать» ручной `Ctrl+V` в Блокноте работает.
- [ ] Внутреннее копирование не создаёт дубль записи или изменения timestamp из-за собственного clipboard event.

## P0 — иконки окон

**I-01. Окно «Изменить запись»**

- [ ] Открыть запись через кнопку «Изменить» или `F2`.
- [ ] Слева от заголовка — **фирменная G-иконка GeniaClipboard**, а не стандартная WinForms/Windows-иконка.
- [ ] Та же иконка выглядит чётко в панели задач и при переключении `Alt+Tab`, если окно там отображается.

**I-02. Остальные диалоги**

- [ ] Проверить окно «Настройки», запрос пароля Portable Vault и обычное главное окно — используется согласованная иконка приложения.
- [ ] Иконка не меняется на стандартную после сворачивания, разворачивания и повторного открытия окон.

## P1 — внешний вид

- [ ] «Вставить» — синяя кнопка, когда доступна; отключённая версия выглядит неактивной.
- [ ] «Очистить» — красная кнопка; перед очисткой появляется подтверждение.
- [ ] В списке истории видны **тонкие, малозаметные горизонтальные разделители**, без вертикальных линий.
- [ ] Выделение строки, закреплённые и sensitive-записи остаются читаемыми.
- [ ] При изменении размера окна и возвращении из трея рядом с поиском нет синих штрихов/артефактов.
- [ ] Статус `Windows Vault / Portable Vault · Записей: N` не обрезается кнопками при узком окне.
- [ ] Вкладки «Безопасность» и «История» по возможности открываются без вертикальной прокрутки на обычном экране.
- [ ] Проверить масштаб Windows **100%, 125%, 150%**: кнопки не накладываются на поля; при необходимости прокрутка работает.
- [ ] В окне редактора многострочный текст читаем и прокручивается; нижние кнопки не перекрывают текст.

## P1 — функциональность истории

- [ ] Копирование новых строк добавляет их в историю.
- [ ] Внешний точный дубль не создаёт второй экземпляр; внутреннее копирование GeniaClipboard не переупорядочивает историю.
- [ ] Поиск отфильтровывает список, не удаляя данные.
- [ ] `Ctrl`+клик, `Shift`+клик и `Ctrl+A` выделяют ожидаемые записи.
- [ ] `Delete` удаляет только выбранные записи; закрепление доступно для одной записи.
- [ ] Изменение текста через `F2` сохраняется после закрытия и повторного запуска.
- [ ] «Экспорт TXT» предупреждает об открытом тексте и создаёт читаемый UTF-8.
- [ ] Двойной клик по подписям интерфейса не копирует их в системный буфер.

## P1 — Privacy Core и сохранность

- [ ] Windows Vault открывается после перезапуска, прежние записи на месте.
- [ ] Portable Vault открывается с правильным паролем; неправильный пароль не стирает историю.
- [ ] Private Session не записывает историю на диск и не пишет TXT-журнал.
- [ ] Выход из Private Session уничтожает только временную историю, постоянный Vault не меняется.
- [ ] Настройки сохраняются: хоткей, лимит истории, срок хранения, исключённые приложения, автозапуск.
- [ ] Конфиденциальные записи не попадают в автоматический TXT-журнал.
- [ ] Если автожурнал включён, пользователь понимает, что обычные записи в нём **не зашифрованы**.
- [ ] После обновления с предыдущей версии старые данные и настройки доступны; файл истории не перезаписывается в случае ошибки расшифровки.
