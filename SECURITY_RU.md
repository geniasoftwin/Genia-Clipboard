# Политика безопасности

[English](SECURITY.md) · **Русский**

## Поддерживаемая версия

Текущая поддерживаемая ветка — `0.5.x`.

## Модель безопасности

GeniaClipboard — локальный менеджер буфера обмена. Clipboard по своей природе доступен программам, работающим в той же пользовательской Windows-сессии.

В 0.5.0 постоянная история защищена authenticated encryption:

- данные истории шифруются AES-256-GCM;
- Windows Vault использует случайный 256-битный ключ под защитой Windows DPAPI текущего пользователя;
- Portable Vault получает 256-битный ключ из мастер-пароля через PBKDF2-HMAC-SHA256;
- мастер-пароль Portable Vault на диск не записывается;
- изменение/повреждение ciphertext приводит к отказу расшифровки, а не к тихому принятию данных.

Шифрование защищает данные **на диске**. Оно не является защитой от malware, уже работающего с достаточными правами в той же Windows-сессии и имеющего доступ к clipboard или памяти процесса.

## Clipboard Firewall

GeniaClipboard умеет:

- учитывать privacy-маркеры Windows clipboard;
- исключать выбранные процессы;
- не сохранять собственные clipboard-записи;
- эвристически распознавать ряд high-confidence секретов;
- автоматически удалять sensitive-записи;
- очищать системный clipboard через заданное время;
- работать в Private Session только в памяти.

Sensitive detector работает best-effort и не гарантирует обнаружение каждого секрета.

## Незашифрованные выходы

Намеренно не шифруются:

- `Data/settings.json` — только настройки, без vault key и мастер-пароля;
- опциональный TXT-журнал;
- ручные TXT-экспорты.

Sensitive-записи и Private Session не пишутся в автоматический TXT-журнал. Ручной экспорт требует явного подтверждения.

## Сообщение об уязвимости

Не публикуйте в открытом issue реальные пароли, токены, персональные данные или содержимое clipboard.

Несекретные отчёты можно отправлять через issue с минимальным воспроизводимым примером. Если детали чувствительные, сначала свяжитесь с владельцем репозитория через GitHub и не прикладывайте реальные секреты.
