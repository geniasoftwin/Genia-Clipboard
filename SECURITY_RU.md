# Политика безопасности

[English](SECURITY.md) · **Русский**

## Поддерживаемая версия

На текущем этапе поддерживается последняя опубликованная ветка `0.4.x`, сейчас — `0.4.4`.

## Модель безопасности

GeniaClipboard — локальный менеджер буфера обмена и по своей природе работает с потенциально чувствительными данными.

- `Data/history.json`, `Data/settings.json` и TXT-журнал хранятся локально **без шифрования**;
- процессы в той же пользовательской сессии Windows в принципе могут читать или изменять системный буфер;
- приватный clipboard-format GeniaClipboard предотвращает самодублирование, но не является механизмом изоляции;
- приложение не может надёжно определить, является ли текст паролем, токеном или другой тайной.

Перед копированием чувствительных данных рекомендуется временно приостановить сбор и отключить автожурнал.

## Защитные меры

Текущая версия ограничивает размеры записей и истории, использует потоковый TXT-экспорт, безопаснее заменяет локальные JSON-файлы, проверяет foreground-window перед автоматической вставкой, не использует сторонние `PackageReference`, а GitHub Actions зафиксированы на конкретных commit SHA.

Подробности: `SECURITY_NOTES.md`.

## Сообщение об уязвимости

Не публикуйте в открытом issue реальные пароли, токены, персональные данные или содержимое буфера обмена. Для несекретной информации можно открыть issue с минимальным воспроизводимым примером. Чувствительные технические детали сначала сообщайте владельцу репозитория через GitHub без приложения реальных секретов.
